# 剩余持续时间为 0 且进度不是 100% 的活动

## 标题

剩余持续时间为 0 且进度不是 100% 的活动

## 预计阅读/口语时间

5-10分钟

## 目标长度

750-1,500 字

## 观众

此博客适用于验证 Primavera P6 进度更新的进度计划员、计划工程师、项目控制工程师、项目经理和 PMO 审核员。

## 开口挂钩

如果一项活动没有剩余持续时间，则通常应完成该活动。当同一活动显示的进度低于 100% 时，进度计划会发出混合信号。

## 介绍

Primavera P6 进度计划更新取决于干净的状态信息。剩余持续时间告诉计划完成一项活动还需要多少时间。进度百分比告诉团队根据所选的完成百分比方法已经完成了多少工作。

当剩余持续时间等于 0 但进度不是 100% 时，这两个信号不一致。活动可能已完成，但缺少实际完成时间，或者可能仍有剩余工时，但被错误地更新为零剩余工期。

此指标标识剩余持续时间 = 0 且进度 <> 100% 的活动。目标是零未解决的活动。

## 该参数的含义

此参数检查剩余时间和报告的进度之间的一致性。如果一项活动没有剩余持续时间，通常意味着该活动没有剩余工作需要执行。在这种情况下，进度通常应为 100%，并且活动应具有正确的完成状态。

结果可能取决于活动的完成百分比类型。实物完成百分比、持续时间完成百分比和单位完成百分比的行为可能有所不同。这就是为什么审查应该同时考虑剩余持续时间和完成百分比方法。

高结果表明更新过程可能具有不完整的实际完成日期、不正确的剩余持续时间或不一致的进度条目。

## 为什么这个主题很重要

状态一致性很重要，因为进度数据会提供进度报告、挣值、前瞻性计划和管理决策。

如果某项活动似乎没有剩余工期但尚未完成，则预测可能会低估剩余工时。如果一项活动实际上已完成，但进度仍低于 100%，则报告可能会低估已完成的工作。

这两种情况都会降低对进度计划更新的信任。

## 结果不佳的常见原因

- 已完成活动缺少实际完成时间
- 错误地将剩余时间设置为 0
- 实物完成百分比未更新
- 完成百分比类型被误解
- 从另一个系统导入的进度未经验证
- 标记完成的活动不一致
- 未遵循更新截止流程

## 如何改善结果

### 1、确认工作是否完成

首先检查字段状态。如果活动完成，请确认实际完成日期并使用项目更新程序将进度设置为 100%。

如果工作未完成，则活动的剩余持续时间通常应大于 0。

### 2. 检查完成百分比类型

检查活动是否使用“体力”、“持续时间”或“完成单位百分比”。修正应与项目控制方法相匹配。

例如，如果使用实物完成百分比，则即使剩余持续时间已达到零，进度计划人员也可能需要手动更新物理进度字段。

### 3. 更正计划状态

对于已完成的工作，输入实际完成日期并确认进度为 100%。对于未完成的工作，恢复实际的剩余持续时间并根据所选方法更新进度。

更正后，重新计算计划并重新运行指标。

## 示例场景

计划更新显示“安装电缆桥架”，剩余持续时间 = 0，实际完成百分比 = 85%。该活动有实际开始但没有实际结束。

进度计划员与现场工程师核实后得知安装尚未完成。工作人员仍需要三天时间来完成遗留问题清单工作和最后的支持。

进度计划人员将剩余持续时间恢复为三天，并将实际完成百分比保持在 85%。该活动现在反映了已完成的工作和剩余的工作。

## 推荐的改进计划

- 第一天：运行指标并识别受影响的活动。
- 第 2-3 天：与负责人确认完成状态。
- 第 4-5 天：正确的实际完成时间、剩余持续时间和进度字段。
- 第 6 天：审查报告和挣值输出。
- 第 7 天：重新评估指标并记录结果。

## 要避免的错误

避免假设剩余持续时间 = 0 始终意味着工作已完成。先确认状态。

避免在未检查活动是否实际完成的情况下将进度更改为 100%。

避免忽略完成百分比类型。错误的更正可能会产生新的报告问题。

## 要点

- 剩余持续时间 = 0 且进度 <> 100% 是状态不一致。
- 目标是零未解决的活动。
- 一起检查实际完成时间、剩余持续时间和完成百分比类型。
- 已完成的工作应正确结束。
- 未完成的工作应保留实际的剩余工期。

## 结论

该指标可帮助进度计划人员捕获小但重要的更新问题。问题不仅仅在于屏幕上的数字；还在于屏幕上的数字。它会影响完成报告、预测质量以及对更新的信心。

管理此指标可以保持活动状态清晰，并使 Primavera P6 报告更容易信任。
